# Silvio Realistic

Site de portfólio de Silvio Muniz (`@silviorealistictattoo`), tatuador de realismo e cover up no Rio de Janeiro.

Feito com [Astro](https://astro.build) e CSS puro, publicado no GitHub Pages.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra http://localhost:4321/silviorealistic/. Requer Node 20.3 ou superior. Mais detalhes em [CLAUDE.md](CLAUDE.md).
